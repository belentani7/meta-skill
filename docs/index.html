Control antes de inferencia.

El router compara señales léxicas en español, portugués e inglés con un índice editable. Expone sus coincidencias, recomienda un tier y estima costes únicamente cuando dispone de tarifas aplicables. No ejecuta el modelo ni garantiza calidad o ahorro.

Del texto a una recomendación.

  1. 01

    Clasificar. Doce arquetipos de tareas con reglas y umbrales inspeccionables.

  2. 02

    Revisar. Confianza heurística y abstención; una puntuación no equivale a una probabilidad calibrada.

  3. 03

    Evaluar. Harness JSONL para cobertura, macro-F1 y errores por clase sobre datos etiquetados.

Ejecuta una tarea real.

Clona el repositorio y ejecuta el CLI con Python. No requiere instalar paquetes.

git clone https://github.com/belentani7/meta-skill.git
cd meta-skill
python3 meta-skill/scripts/route.py --json "Build a responsive React component"

La salida es una recomendación explicable. Si no hay precio verificable, el coste se considera desconocido.
