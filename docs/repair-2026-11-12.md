# Reparación de la publicación

## PRD / SRS
La página desplegada debe explicar el router existente y permitir llegar a su instalación y evaluación sin enlaces vacíos ni promesas de producción no verificadas.

## Diseño / ADR
Se reutilizan los estilos y el portapapeles accesible existentes. La portada anterior se conserva como texto. El favicon se publica dentro de docs para que funcione con Vercel y Pages. El catálogo conserva ambas versiones de metadatos, con medición histórica explícita.

## Plan y validación
Verificar los enlaces locales y los contratos del portapapeles; ejecutar pruebas del router, Evaluation Lab y doctor. No se modifican modelos, tarifas ni algoritmos.
